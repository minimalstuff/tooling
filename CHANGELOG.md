# Changelog

All notable changes to @minimalstuff/tooling are written here for the people who use it. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/). Before 1.0, a minor version can contain breaking changes (see the README).

## [Unreleased]

## [0.9.0] - 2026-11-07

### Added

- `tooling check-release` fails (exit code 1) when `pnpm-lock.yaml` still has a `pnpm patch`, or a `@minimalstuff/*` dependency that is not a registry version (`link:` outside the repository, `file:`, git or tarball URL). It never prompts, so it runs in CI and in a Dockerfile.
- A reusable GitHub workflow, `minimalstuff/tooling/.github/workflows/release.yml`, cuts a release (version bump, tag, GitHub release) in CI after running `tooling check-release`, with a deploy key kept in an environment secret, so only CI can create tags.

## [0.8.2] - 2026-11-04

### Fixed

- With `react: true`, `react/only-export-components` is off in test files (`*.test.*`, `*.spec.*` and `tests/`), where Fast Refresh never applies, so test helpers that re-export a library next to a custom `render` are no longer flagged.

## [0.8.1] - 2026-11-04

### Fixed

- With `adonisjs: true`, `typescript/consistent-type-imports` is off in `app/`, `commands/` and `providers/`, so `oxlint --fix` no longer turns injected classes into type imports and breaks dependency injection.

## [0.8.0] - 2026-11-01

### Added

- The CLI installs `@adonisjs/eslint-plugin` when the AdonisJS preset is selected.
- The package ships a LICENSE file (MIT).

### Changed

- **Breaking:** `@adonisjs/eslint-plugin` is now an optional peer dependency instead of a dependency of this package. AdonisJS projects (`adonisjs: true`) must install it themselves with `pnpm add -D @adonisjs/eslint-plugin`.
- **Breaking:** the base oxlint preset enables the `promise` plugin and new rules, so existing projects can see new lint results. `promise/param-names`, `promise/no-return-in-finally`, `promise/no-multiple-resolved`, `promise/no-new-statics` and `promise/valid-params` are errors. `no-await-in-loop` (off in test files) and `promise/no-nesting` are warnings.
- The CLI installs all packages in one step at the end, after writing the config files. If the install fails, it prints the command to run yourself.
- The CLI offers VS Code settings only when OXC is selected, since they configure the OXC extension.
- The CLI exits with code 130 when cancelled, and with code 1 and a message when it is not run in an interactive terminal.
- **Breaking:** the oxlint preset reports relative imports (`./`, `../`) by default, so code uses Node subpath imports (`#folder/file.ts`). Opt out with `subpathImports: false`. The CLI sets it when the project declares no subpath imports. See [Upgrade from 0.7 to 0.8](https://github.com/minimalstuff/tooling/blob/main/docs/migrating.md#upgrade-from-07-to-08).

### Fixed

- The AdonisJS oxlint rules load with strict pnpm (`hoist: false`).
- The CLI escapes workspace paths written into the generated Knip config, so a directory name containing a quote or a backslash no longer breaks `knip.ts`.

## [0.7.0] - 2026-10-22

### Added

- Knip preset (`@minimalstuff/tooling/knip`) and Knip support in the CLI.
- The CLI lets you pick which presets to set up, keeps your existing scripts and asks before overwriting files.
- `vitest` option in the oxlint preset, which enables the `vitest` plugin.
- `adonisjs` option in the oxfmt preset, which ignores AdonisJS default paths.
- The oxfmt preset sorts imports natively (`sortImports`), replacing perfectionist.

### Changed

- **Breaking:** `minimalstuffPreset` now returns the root oxlint config instead of an entry for `extends`. The `*_IGNORE_PATTERNS` exports and the `perfectionist` option are removed. See [Upgrade from 0.6 to 0.7](https://github.com/minimalstuff/tooling/blob/main/docs/migrating.md#upgrade-from-06-to-07).
- **Breaking:** Node >= 26 is required, along with oxlint >= 1.89.0, oxfmt >= 0.74.0 and oxlint-tsgolint >= 7.0.2004.
- **Breaking:** the oxlint preset reports the `correctness` category as errors, and `typescript/switch-exhaustiveness-check`, `typescript/only-throw-error`, `typescript/return-await`, `typescript/prefer-promise-reject-errors` and `typescript/consistent-type-imports` are errors.

### Fixed

- Config files generated by the CLI pass `oxfmt --check`.
- The EditorConfig preset indents YAML files with spaces.

## [0.6.0] - 2026-05-11

### Added

- The CLI can configure VS Code settings (`vscode` tool).

### Changed

- The CLI no longer pre-selects tools that already have a config file at the repository root.

## [0.5.0] - 2026-04-26

### Added

- The CLI detects AdonisJS and React projects.

### Changed

- `minimalstuffPreset` enables `perfectionist` import sorting by default.

## [0.4.0] - 2026-04-26

### Added

- The formatting presets ignore AdonisJS default paths.
- The linting preset ignores AdonisJS default paths and enables additional rules.
- The CLI adds scripts to your `package.json`.

## [0.3.0] - 2026-04-10

### Fixed

- The CLI edits oxlint and oxfmt config files that contain comments (JSONC) without breaking them.

## [0.2.1] - 2026-04-09

### Changed

- Several TypeScript lint rules are disabled in the oxlint preset.

## [0.2.0] - 2026-04-08

### Added

- `oxlint-tsgolint` is a peer dependency, and the preset enables more rules.

### Removed

- The CLI no longer sets up a `tsconfig`.

## [0.1.3] - 2026-04-02

### Changed

- The EditorConfig preset indents Markdown files with two spaces.

## [0.1.2] - 2026-04-02

No user-visible changes.

## [0.1.1] - 2026-04-02

No user-visible changes.

## [0.1.0] - 2026-04-02

### Changed

- The framework preset targets React instead of Vue.
